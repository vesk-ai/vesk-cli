# Vesk website — GitHub Pages branch

This branch holds the built static site at the repository root, ready for GitHub Pages.
Source and docs live on `ves-28-website` (`site/`). To update this branch, copy the contents
of `site/` from that branch to the root here and commit.

Publish: repo Settings → Pages → Source: "Deploy from a branch" → Branch `gh-pages`, folder `/ (root)`.
Site URL will be https://vesk-ai.github.io/vesk-website/ (all asset paths are relative).
